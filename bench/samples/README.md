# 测试语音样本（不入库）

用于 I2 关卡 A 的识别基准与 I3 的判向 / 翻译验收。音频文件已在 `.gitignore` 中排除，只提交本 README 与 `.txt` 参考文本。

## 怎么录

- 任何格式都行（m4a / wav / mp3 / aac），我会统一转成 16 kHz 单声道 wav。最省事：**手机自带录音机录完 AirDrop / 微信文件传到 Mac**。
- 每个文件一句话，3–10 秒；安静环境一组、嘈杂环境（街边 / 餐厅）一组；每种语言各 5–10 句。
- 说日常会用到的话（问路、点餐、报数字 / 时间 / 价格、人名地名），不要念稿腔。
- 同名 `.txt` 写你认为正确的文字（可选但强烈建议，有它才能算字错率）。

## 目录约定

```
bench/samples/
  zh-CN/            普通话     quiet-01.m4a  quiet-01.txt  noisy-01.m4a ...
  zh-CN-sichuan/    四川话     （先做这个）
  en/               英语
  yue-HK/           粤语       （其次）
```

## 用途

| 里程碑 | 用法 |
|---|---|
| I2 关卡 A | 跑端侧模型：RTF / 首包 / 字错率（有 .txt 时） |
| I3 | 判向（中英自动判别）、翻译质量抽查 |
| I5 | 会议录音（10–30 分钟，单独放 `bench/samples/meeting/`） |
