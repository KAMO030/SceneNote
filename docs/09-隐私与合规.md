# 09 · 隐私与合规（客户端视角）

> **这篇讲什么**：用户的数据到底去了哪、怎么让用户随时看见、要哪些权限、录音要不要告知对方、上架要满足什么。没有服务器，所以合规负担比常见方案轻很多，但客户端该做的一样不少。
> **谁该看**：产品、法务、开发。

## 先看这个

1. **默认策略一句话**：识别在本地，只有文字上云做润色 / 翻译；录音要上云，必须用户明确选择。界面顶部永远有一个胶囊告诉你"现在数据去哪了"。
2. **每个云厂商首次启用都弹一次显式同意**，随时可撤回。中国区默认只列国内厂商并公示备案号，境外厂商通过"自定义端点"保留，不做两个版本的 App。
3. **面对面对话的录音告知由礼貌卡完成**：转向对方的半屏用对方的语言写"我在用翻译听你说话"；对方的声音默认不存，只存文字。
4. **权限最少化**：麦克风必需；通知、日历、姿态传感器、局域网、蓝牙、悬浮窗都可选或按需；**不申请相册权限**（用系统选择器）。
5. **没有服务器带来的简化**：不用做算法备案、ICP、数据出境评估；只需在调用已备案模型 API 时向属地网信办登记并公示；端侧模型不触发登记；局域网 P2P 不经任何服务器。
6. **模型许可要在上架前法务复核**（首发三个方言模型包的许可链有不清楚的地方）。

---

## 数据流向

1. **常驻可见**：录音页 / 实时页顶部胶囊显示"仅本机 / 音频段 → 某厂商 / 仅文本 → 某厂商 / 已授权 N 段 / 局域网 → N 台设备（仅音频）"。各场景的默认档位与 01 的场景表逐行一致：会议 / 口述 / 面对面 / 屏内默认"仅文本上云"，方言家庭默认"仅本机 + 逐段授权"，采访默认"锁定"。
2. **显式同意**：首次启用每个云厂商弹"你的录音 / 文本将发送到 {厂商}（{区域}）"（App Store 5.1.2(i) 要求），可随时撤回。厂商清单按系统区域和商店区域过滤默认显示项，用户可在设置里"显示全部"。
3. **去向账本的诚实边界**：只记三类——第三方 API 出站、模型资产下载（含方言包与端侧 NMT 语言对模型，经 Background Assets / Play Asset Delivery / 手动导入）、局域网出站。若用户在 v1.1 启用系统识别 / 系统翻译插件，其听写包、翻译包由苹果 / 谷歌下载，不在账本里，隐私政策里写明。局域网加密是应用层的，不写"TLS"。

## 录音告知

4. 录音时有常驻通知 / Live Activity + App 内红点 + 可选开场提示音；会议场景有"已告知参会者"勾选（《民法典》1032 / 1033、PIPL、美国部分州要求双方同意）。**面对面对话由对方半屏的礼貌卡告知**（对方语言 + 录音图标）；M0 纯仅听时 App 内常驻录音指示；德 / 法 / 日等地区首次使用弹一次合规说明，不强制阻断。**对方音频默认不落盘只存文本；不支持通话录音。**

## 权限

5. **最少化**：麦克风必需；**通知可选**（拒绝后回访机制退化为小组件 / 待办条）；日历可选（场景推断）；姿态传感器用于自动进 M1，可关；定位 / Wi-Fi 默认关且 v2；局域网权限只在 v1.1 多机模式按需；蓝牙只在 BLE 兜底（v2）按需；**相册不申请**（用系统选择器）；**悬浮窗权限只在选悬浮窗载体时按需，画中画免权限**。
6. **iOS**：麦克风、语音识别、日历、相册写入（只写不读）、局域网 + Bonjour（v1.1）、运动传感器的用途说明；`PrivacyInfo.xcprivacy` 如实声明，不追踪；录屏扩展和主 App 各自一份隐私清单；录屏路径的文案不出现"录制 / 下载 XX 音频"。
7. **Android**：录音、通知（可选）、麦克风前台服务、**投屏前台服务**、附近 Wi-Fi 设备（v1.1）、悬浮窗（v1.1）；数据安全表标"音频 / 语音：用户启用云识别时传第三方"；**Play Console 要为两类前台服务各提供演示视频**（屏内的演示视频是 MVP 前置任务）；**首次进入屏内 S1 时展示显著披露页**（抓取应用音频、是否离开设备、Key 去向、锁屏停止、状态栏 chip）；不用无障碍服务。

## 数据处理

8. **敏感信息脱敏**：上云前把手机号 / 身份证 / 银行卡 / 邮箱替换成占位符，返回后还原；界面明示"辅助手段，非强保证"；实时路径同样处理（延迟可忽略）。
9. **中国区**：只调用已备案模型 API，需向属地网信办登记并公示；无后端免去算法备案、ICP 与出境评估；端侧模型不触发登记；局域网 P2P 不经任何服务器。
10. **模型许可**：sherpa-onnx 运行时 Apache-2.0；**首发三个模型包的转换仓库没写许可字段，微调权重标 Apache-2.0 但基座受 FunASR 模型许可约束**；其他模型许可待核对；libopus BSD——全部列入上架前法务复核清单；"关于"页公示模型清单与许可。
11. **可删除**：一键导出整库 zip；"删除所有数据"真实清空（含声纹、P2P 会话密钥、屏内缓存）。
12. **导入的内容只当数据**：`.scene` / `.voxnote` / 多机"提示"文本 / 网页字幕请求里的任何文字都不进系统提示，也不覆盖本机的厂商和路由设置。

## 版权与平台政策（屏内）

13. 不绕过被播放 App 的拒绝抓取、DRM、防截屏标记；抓不到时诚实提示并引导用系统实时字幕；字幕共享只传原文文字不转播第三方音频；任何文案不出现"绕过版权"；商店描述按等级措辞（CORE 可写、ANDROID_ENHANCED 加限定、IOS_EXPERIMENTAL 标实验、FALLBACK 只在帮助页）。

## 多机会话的对端知情

14. 加入房间的二维码 / 列表明示"你的语音将以加密音频流发给房间成员，由他们各自在本机**或其配置的云服务**翻译"；说话方界面常驻"N 位听者使用云端识别（百炼 / 火山）"；发起人可设房间"仅端侧识别"；听者端明示"你收到的是原声音频，翻译在你本机（或你配置的云服务）完成"。
