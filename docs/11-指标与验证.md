# 11 · 关键指标与验证假设（全部本地可度量）

> **这篇讲什么**：这个产品建立在 17 条假设上，每条假设对应哪个本地指标、MVP 期的目标是多少、怎么量。所有指标只存手机本地，不上传。
> **谁该看**：产品、数据、开发。

## 先看这个

1. **灰度期只盯 8 条主线**：H1 场景入口提升频次、H6 信任层降低摩擦、H7 产物值得分享、H10 回访有效、**H11 实时翻译达标可靠、H12 零社交摩擦成立、H15 屏内"看完留下东西"、H17 零 Key 翻译可用且够快**。任何一条不成立，对应层级的 v1.1 投入立刻降级，不继续堆功能。
2. **诚实说明**：指标只反映留下来的用户（流失的人不会导出数据、不会接受访谈）。留存 / 流失用商店后台的粗粒度数据、内测名单回访、导出包里的"安装日期 vs 最后录音日期"分布来替代。
3. **延迟指标也只是本机自测**（终点是语音写入输出缓冲的时刻，不含蓝牙入耳的 0.15–0.25 秒），旗舰验收以实验室真机脚本为准。

## 假设与指标

| 假设 | 指标 | MVP 期目标 | 怎么量 |
|---|---|---|---|
| H1 场景绑定入口能提升使用频次 | 入口触发占比、次周活跃 | 绑定用户会话频次 ≥ 未绑定的 1.5 倍 | 按场景聚合 |
| H2 场景推断少改一步 | 推断命中率、预热后当日首次 M0 触发率 | ≥ 60%（日历命中会议）；出门预热后当日 M0 触发 ≥ 50% | 推断 vs 最终场景 |
| H3a 端侧路径纠错越用越准 | 端侧纠错率、S0 替换保留率、纠错入口打开率 | 第 4 周比第 1 周下降 ≥ 15%，且纠错入口打开率不降 | 每千字纠错次数 |
| H3b 云端路径纠错越用越准 | 云端纠错率、热词命中率 | 第 4 周比第 1 周下降 ≥ 30% | 仅有 Key 的用户 |
| H4 润色越用越像自己 | 润色接受率 | 从约 70% 升到 ≥ 85%（v1.1 加个人示例后） | 接受 / 校验通过段 |
| H5 知识库产生复用 | 搜索命中率、复用动作数（含跳回视频） | 有 ≥ 20 条笔记的用户每周搜索 ≥ 2 次 | 全文检索日志 |
| H6 信任层降低方言 / 面对面场景摩擦 | 本地占比、精修回退率、方言场景录音数、逐段授权率、礼貌退出率 | 精修回退率 ≤ 10%；礼貌退出率 ≤ 15% | 账本与修订表 |
| H7a 产物值得分享（有 Key / 系统模型） | 24 小时内分享率 | 会议场景 ≥ 30% | 分享面板调用计数 |
| H7b 产物值得分享（零 Key 规则稿） | 24 小时内分享率 | ≥ 15%；方言家庭留言卡 ≥ 40% | 同上 |
| H8 三种产物能被导入 / 加载 | 笔记包导入数、场景包导入数、字幕导出数 | 存在即验证格式可用 | 本机计数 |
| H9 云端 Key 启用率 | 已配置 Key、云端分钟占比、按需引导转化率 | ≥ 15% 用户配置 Key；场景内引导转化 ≥ 30%（中英以外语言对的面对面引导 ≥ 40%） | 本地开关状态 |
| H10 回访机制有效 | 3 天提醒打开率、小组件点击率、通知权限授予率 | 录后 3 天提醒打开率 ≥ 20% | 通知 / 小组件交互 |
| **H11 实时翻译达标且可靠** | 延迟 P50 / P95（本机口径）、降级率、耳机断开次数、30 分钟掉线率 | 旗舰机混合档中英本机 P50 ≤ 1300 ms / P95 ≤ 2000 ms（对应实验室 1500 / 2200）；粤语 M0 本机 P50 ≤ 2000；耳机断开不外放由实验室验收；30 分钟掉线率 0 | 按档位 / 语言 / 机型分组 |
| **H12 零社交摩擦成立** | M0 → M1 升级率、手动翻转率、外放黄标占比、实时会话时长 | 手动翻转 ≤ 10%；外放黄标 ≤ 10%；面对面会话中位时长 ≥ 3 分钟 | 会话事件 |
| **H13 实时是高频入口** | 周实时会话数、周实时分钟数、慢路径完成率 | 面对面 / 屏内周会话数 ≥ 录音场景的 2 倍；慢路径完成率 ≥ 90% | 会话表 |
| **H14 术语回流让实时翻译更准** | 实时术语命中数、实时纠正率 | 第 4 周比第 1 周命中上升、纠正率下降 ≥ 20% | 句子表 |
| **H15 屏内"看完留下东西"** | 周屏内会话数、字幕导出数、观影入库词数、精修轨导出占比、首条字幕耗时 | 有 ≥ 3 次屏内会话的用户中 ≥ 50% 至少导出一次字幕或加 ≥ 5 个生词；S4 首条 ≤ 5 秒 | 屏内会话表 |
| **H17 零 Key 翻译可用且够快** | 零 Key 翻译可用率（实时会话开始时中 ↔ 英 NMT 模型已就绪的占比）、NMT 单句延迟 P50 / P95、云翻译超时降到 NMT 的占比 | 模型就绪率 ≥ 90%（出门预热强制预下载后）；旗舰机 NMT 单句 P50 ≤ 300 ms / P95 ≤ 600 ms（目标，待基线机实测校准）；降级占比按网络分组记录 | 会话表按语言对 / 机型分组 |
| **H16 Android S1 可抓性与摩擦** | 抓取被拒率、冷启动耗时、锁屏中断率、S3 降级率 | 被拒率按 App 分布记录；冷启动 ≤ 8 秒；锁屏中断后恢复率 ≥ 60% | 屏内会话表 |

## 假设不成立时怎么办

- H11 不达标 → v1.1 的双机 P2P（M8 / M9）延后，先优化单机管线。
- H12 不成立（手动翻转 > 25%）→ 判向默认改为"固定方向 + 滑动翻转"。
- H15 不成立 → 屏内 v1.1 只做耳机配音（S2），不做悬浮窗 / OCR 自动刷新。
- H17 不成立（模型就绪率 < 90% 或 NMT 延迟超标）→ 中 ↔ 英 NMT 包改为随包内置并重议首装阈值（附录 B 待决策 32）；延迟超标则基线机离线档改逐句非流式、beam 1。
- H3a / H3b、H2、H4、H5、H13、H14、H16 需要数据积累，v1.1 复盘。
