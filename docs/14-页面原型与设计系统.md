# 14 · 页面原型与设计系统

> **这篇讲什么**：17 张可点击原型画板分别长什么样、怎么点、怎么串成流程；`core/design-system` 的 Token 与组件怎么用；给另一个会话 / 另一个人接手时从哪里拿到原型。
> **谁该看**：设计、开发（做页面迁移时以此为准）、以及任何要参考原型的 Claude 会话。
> 设计语言的"为什么"在 [07 §7.14](07-技术架构-平台扩展与协议.md)，本篇只讲"长什么样、怎么点"。

## 0. 原型在哪里、怎么给别人 / 别的会话

| 方式 | 适用 | 怎么做 |
|---|---|---|
| **画布链接**（可点击、可编辑、可评论） | 人看；同一 Claude 账号的其他会话 | https://claude.ai/artifact/MAj8d8pkjFPWt5AHG3DZpd 。另一个 Claude 会话把这个链接贴进去，它可以用 Artifact 工具 `read` 该画布：`project/canvas.json` 是画板索引，`project/<屏名>.dc.html` 是每一屏的完整 HTML + 交互逻辑。分享给别人：画布页面右上角的分享菜单（默认私有）。 |

## 2. 视觉规则（原型与代码共用）

- **两层模型**：功能层才是玻璃——浮动胶囊 Tab 栏（66 pt，距底 28 pt）、44 pt 圆形玻璃导航按钮、玻璃标题胶囊、底部 dock（88 pt）、sheet 材质。内容层（卡片、气泡、字幕、列表）不透明，永不用玻璃。玻璃无固有色，其上标签单色；一个视图只有一个着色主按钮。
- **玻璃参数**（原型 CSS `.glass`）：填充 58% 白 / 72% 黑，`backdrop-filter: blur(26px) saturate(1.8)`，0.5 px 描边、顶部高光线、对角高光渐变（模拟折射）、14 px 投影；`.glass-clear` 用于视频画面上（28% 黑 + 压暗）；`.rt .glass` = 降低透明度回退（98% 不透明、无模糊、无高光）。
- **色**：`tint #0E7C86`（白字 4.95:1）；黄标 `#FFF4D6 / #8A4B00` 只给外放类降级；破坏性 `#FBE5E3 / #A32820`；深色下 tint `#4FC3CC`。深色仅用于 M3 双屏与 S4 播放器（沉浸式媒体界面允许常驻深色）。
- **字**：Apple 刻度 34 / 28 / 22 / 20 / 17 / 16 / 15 / 13 / 12 / 11；对方半屏与速译卡 ≥ 28 pt。
- **形**：按钮胶囊（iOS 26）；卡片 22 pt、分组 18 pt、sheet 顶角 28 pt；触控 ≥ 44 pt（Android 48 dp）。
- **反馈**：胶囊、行内提示、震动；不弹窗；Alert 只给不可撤销动作。

## 3. 原型 ↔ `core/designsystem` 映射

| 原型 CSS | 组件 | 备注 |
|---|---|---|
| `.ph` + `.scroll` + `.navg` + `.tabbar/.dock` | `GlassScaffold(topBar, bottomBar) { content }` | 内容自己留出顶部 104 dp / 底部 140 dp |
| `.gbtn.glass` / `.gttl.glass` / `.gcap.glass` | `SceneNavBar(title, onBack, trailing)`、`SceneIconButton(glass = true)`、`SceneGlassCapsuleButton` | |
| `.tabbar.glass > .tab` | `SceneTabBar(tabs, selectedIndex, onSelect)` | 选中项白色 80% 胶囊 + tint |
| `.dock.glass` | `SceneDock { … }` | 主钮 72 dp prominent，两侧 56 dp 圆钮 |
| `.sheet.glass-flat` + `.grab` + 取消 / 完成 | `SceneSheet(visible, onDismiss, title, onDone)` | 下滑 96 dp 关闭 |
| `.group / .row / .sep / .sec / .fn / .ic` | `SceneGroup / SceneRow / SceneDivider / SceneSectionHeader / SceneSectionFooter / SceneRowIcon` | |
| `.card` | `SceneCard(outline = tint)` | |
| `.btn-p / .btn-g / .btn-y / .btn-r`、`.rbtn` | `SceneButton(style = Prominent / Gray / Tinted / Plain / Warning / Destructive)`、`SceneIconButton` | |
| `.cap-t / .cap-g / .cap-y / .cap-r` | `SceneCapsule(tone = Tint / Gray / Warning / Destructive, icon)` | |
| `.seg` | `SceneSegmentedControl(options, selectedIndex, onSelect)` | 白色胶囊滑动 |
| `.tg` | `SceneToggle(checked, onCheckedChange)` | 51×31 |
| `.rt`（reduceTransparency） | `AccessibilityPrefs.reduceTransparency` → `rememberGlassSpec()` 不透明回退 | 系统偏好自动读取 |
| `.glass` 的 backdrop-filter | `Modifier.glass(shape)` 内 `GraphicsLayer` 嵌套重绘 + `BlurEffect` | **iOS 暂关**（Skiko 崩溃，见验收记录）；Android ≥ 12 开；iOS 26 原生宿主待接 |

代码里的用法骨架：

```kotlin
GlassScaffold(
    topBar = { SceneNavBar(title = "M0 仅听", onBack = onBack, trailing = { SceneCapsule("混合档 · 正常", tone = CapsuleTone.Tint) }) },
    bottomBar = { SceneDock { /* 速译 / 暂停 / 结束 */ } },
) {
    Column(Modifier.fillMaxSize().verticalScroll(rememberScrollState()).padding(top = 104.dp, bottom = 140.dp)) { /* 内容层 */ }
}
```
