# 演示视频 · 操作脚本

一镜到底，约 58 秒，iPhone 17 Pro 模拟器录屏，零 Key（全程本机识别 + 本机翻译）。
故事：在国外问路。**对方说英语**（Mac 的 Samantha 语音从扬声器播出，模拟器麦克风收音），**我说普通话**（Tingting 语音）。

## 前置准备（不录）

| 项 | 做法 |
|---|---|
| 语音包 | 静音检测、中英识别、多语言识别、**英 → 中翻译、中 → 英翻译** 都已下载 |
| 译文朗读 | 设置 → 朗读 → 译文朗读 = **关**（否则 App 读出的译文会被麦克风再听进去，串成"我说的话"） |
| 首次提示 | 先把整套流程干跑一遍，让各页的首次轻提示都出现过 |
| 状态栏 | `xcrun simctl status_bar <udid> override --time 9:41 --batteryLevel 100 --wifiBars 3 --cellularBars 4` |
| 环境 | 关掉 Mac 通知声；音量保持能让麦克风收清楚 |
| 素材 | `say -v Samantha -o en1.aiff "…"`、`say -v Tingting -o zh1.aiff "…"`，播放用 `afplay` |
| 录制 | `xcrun simctl io <udid> recordVideo --codec h264 --force demo.raw.mp4`，Ctrl-C 结束 |

2026-09-18 首版实录：原始 106 s → 剪后 53 s，0.9 MB。

台词：

| 文件 | 谁 | 内容 |
|---|---|---|
| en1 | 对方 | Excuse me, are you looking for the train station? |
| en2 | 对方 | Go straight, then turn left at the second traffic light. |
| en3 | 对方 | It's about five minutes on foot. |
| zh1 | 我 | 谢谢！请问附近有便利店吗？ |
| en4 | 对方 | Yes, there is one right next to the station. |

不放进演示的：速译（按住说话）——用模拟器工具模拟的长按不稳定，真机录时可以加在结尾。

## 后处理

`simctl recordVideo` 出来的是"画面变了才出帧"的可变帧率，先转成恒定 30 fps，否则静止段在剪辑时会消失：

```bash
ffmpeg -i demo.raw.mp4 -vf fps=30 -c:v libx264 -crf 16 -an cfr.mp4
```

工具驱动的操作之间有 1–3 秒空档，用帧差分找静止段（帧差 < 0.4%），超过 3.4 秒的静止段只保留前 3 秒（留给观众读译文），首页只留 2 秒；然后 trim + concat：

```bash
# 720p、H.264、≤ 15 MB（线上 artifact 单文件上限）；-movflags 让网页边下边播
ffmpeg -i cfr.mp4 -filter_complex_script filter.txt -map "[out]" -c:v libx264 -crf 23 -preset slow -an -movflags +faststart demo.mp4
# 封面：取首页那一帧
ffmpeg -ss 0.5 -i demo.mp4 -frames:v 1 -q:v 3 poster.jpg
```

放到 `docs/介绍页/video/demo.mp4`（和 `poster.jpg`），页面自动从占位卡切成播放器。
