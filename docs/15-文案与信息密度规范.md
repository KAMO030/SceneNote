# 15 · 文案与信息密度规范（页面文字怎么写）

> 2026-09-17 起对所有用户可见页面生效。背景：I2.5 / I3 / I4 迁移后的页面把执行计划、模块规格里的措辞（M0 / 混合档 / 端侧 / 判向 / 去向账本 / Stage Health…）直接搬上了屏幕，文字挤成一坨，还出现了与当前平台无关的项（Android 上的 Apple Translation）。

## 1. 三条硬规则

1. **用户语言，不用工程语言。** 禁止出现在页面上的词：`M0`–`M12`、`S1`–`S8`、`I3`/`v1.1` 等里程碑、`混合档 / 离线档 / 在线档 / 一体化`、`端侧`、`判向`、`快路径 / 慢路径`、`Stage Health`、`去向账本`、`隐私档`、`zipformer / SenseVoice / Paraformer / CAM++ / Matcha / qwen-mt`（模型名只在「模型与语言包」列表和诊断页出现）、`Egress`、`BYOK`。替换见 §3 词表。
2. **一屏一件事。** 每张卡 / 每组最多 1 行说明（≤ 20 字）；页脚每组最多 1 条（≤ 30 字）；不写"为什么"，只写"是什么 / 做什么"。原型里的解释性长句一律删掉或收进「了解更多」。会话页只显示对话内容 + 一个状态词，不显示装载耗时、路由、引擎、RTF、延迟（这些只在设置 → 诊断）。
3. **只显示当前平台、当前能力有的东西。** 用 `PlatformInfo.isAndroid / isIos` 决定：iOS 显示"快捷指令 / 操作按钮 / Apple 翻译（稍后）"，Android 显示"磁贴 / 快捷设置"；没接的能力直接不显示（不做"禁用行 + 灰字"），除非它是下载语音包 / 连接云端翻译这种用户下一步就能做的事。

## 2. 引导

- 首次启动进入三页引导（跳过后设置里可再看）：① 怎么用（戴耳机 / 手机放胸前 / 对方说话你听译文），② 连不连云端翻译（离线能做什么 · 一键去连），③ 入口（按平台）。
- 会话页首次进入显示一次轻提示（气泡 / 空态文字），例如仅听空态："对方说话，译文会出现在这里并从耳机播放"。
- 状态用一个词 + 颜色：正常 / 离线 / 无翻译 / 语音关；不要拼接三段式胶囊。

## 4. 自查清单（改完一页对照）

- [ ] 页面上 grep 不到 §1 的禁用词
- [ ] 每组 ≤ 1 说明 + ≤ 1 页脚；卡片标题 ≤ 8 字、副标题 ≤ 20 字
- [ ] 与当前平台无关的行不存在（不是禁用，是不存在）
- [ ] 会话页没有工程数据（耗时 / 路由 / 引擎名）
- [ ] 首次进入有一次引导 / 空态提示，之后不再打扰

## 5. 多语言（界面语言）

界面文案默认跟随系统语言：中文（`values-zh`）/ 英文（`values`，兜底）/ 日文（`values-ja`）/ 韩文（`values-ko`），
资源在 `shared/src/commonMain/composeResources/`，Android 13+ 与 iOS 都能在系统设置里按应用改语言（`locales_config.xml` / String Catalog）。
设置 → 语言 → 界面语言 也能手动选（`core/platform/AppLocale`）：Android 立即生效且不重建 Activity（改进程默认 locale 后 `UiLocale.bump()`，Compose 原地重组；13+ 走 LocaleManager，MainActivity 用 configChanges=locale 自己接），
iOS 只能写 AppleLanguages，下次打开生效（弹一次说明，可选「现在退出」）。

**写法**
- Composable 里用 `stringResource(Res.string.xxx)`（导入 `dev.scenenote.core.i18n.stringResource`，不要直接用 CMP 的，否则应用内切语言不重组）；协程 / suspend 里用 `getString(Res.string.xxx)`。
- 纯函数、状态里的文案（路由原因、TTS 原因、错误）用 `UiText`（`core/i18n/UiText.kt`），到 UI 边缘再 `.string()`；平台层抛给用户看的错误用 `uiError(Res.string.xxx)` / `UiException`。
- 语言名 / 场景名 / 模式名走 `ui/i18n/Labels.kt` 的 `langName` / `ScenePreset.title()` / `ModeSpec.title()`，不要直接读 `name` 字段（那是中文源与自定义场景名）。
- 日期用 `dayLabel`，时长用 `duration_*`，带数字的句子用 `%1$d` 占位（CMP 只认 `%N$s` / `%N$d`，`%` 本身不用转义）。
- 只翻界面语言，不翻**内容语言**：礼貌卡 / 退出语（`Phrases.kt`）、对方半屏的固定词（`theirWords`）按对方语言取；LLM 提示词固定中文；给对方看的文字用 `TextStyle.forLang(tag)` 选字体，避免日文按中文字形渲染。
- 日志、`Diag`、内部断言用英文，不进资源。

**加一条新文案**：四个 `strings.xml` 各加同名 key（key 前缀 = 页面 / 模块：`home_` `live_` `settings_` `note_` …），英文优先短句，注意胶囊 / 分段控件里英文比中文长约 30%。
