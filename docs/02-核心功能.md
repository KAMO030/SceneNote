# 02 · 核心功能（五条硬性需求怎么落地）

> **这篇讲什么**：需求文档里的五条硬性要求——方言识别、自动翻译、风格 / 场景切换、自动润色、端云切换——每一条在产品上长什么样、技术上怎么实现、诚实的边界在哪。
> **谁该看**：产品、开发。更深的工程细节在 05 / 06，数据结构在附录 A。

## 先看这个

1. **识别**：不让用户选语言，只选场景。普通话、英文、粤语、四川话能在手机本地识别（**sherpa-onnx 是唯一的端侧识别 / VAD / 声纹引擎，两端一致**；系统自带的识别引擎只作为 v1.1 的可选插件）；上海话、闽南语 MVP 只能走云端（需要 Key），没 Key 时直接告诉用户"不支持"，不拿普通话模型硬识别出一堆乱码。
2. **翻译**：有 Key 时"先润色再翻译"（阿里 qwen-mt 支持术语表注入）；没 Key 时用**端侧 NMT**（opus-mt 中 ↔ 英 int8 模型，每个方向约 80 MB，按语言对按需下载，走和方言包一样的分发通道）——两端一致、不依赖系统 API，语言对模型没下载时提示下载。苹果 / 谷歌的系统翻译降为可选插件（v1.1，设置里手动启用），MVP 不实现、不依赖。粤语翻普通话，没 Key 只能做繁简转换，会明确标注。
3. **风格 × 场景**：场景是首页的卡，风格是卡里的二级选项。换风格不用重新识别，只重跑润色。实时翻译只用一句话级的语气提示（旅行 = 简短礼貌，商务 = 正式全称）。
4. **润色**：五步管线，核心规矩是**不许改事实**（数字、日期、金额、人名、否定词必须原样保留），每一版都存起来可以回滚，用户手改过的段落云端不会自动覆盖。
5. **端云切换**：路由三态 × 隐私档四档一张表定死所有组合；界面顶部常驻一个胶囊，随时告诉你"现在数据去了哪"。

## 2.1 需求 1：中文、英文与方言识别

### 用户看到什么

- **不选语言，只选场景。** 场景卡里有一行"谁在说"标签（普通话 / 粤语 / 四川话 / 上海话 / 闽南语 / 英文 / 自动），录音中可以点切"现在换人说了"，只影响之后的段落。卡面上最多显示两个标签（比如方言家庭 = 粤语 + 普通话；面对面 = A 我 / B 对方），其余折叠。
- "自动"只在 SenseVoice 能分辨的普通话 / 粤语 / 英文之间自动判断；四川话、上海话、闽南语必须手动点。
- 标签用颜色说真话：**绿 = 本地成熟**，**蓝 = 云端**，**灰 = 本地只有草稿级**，**蓝框空心 = 本地没有、只能云端**。录音前弹一次该方言的诚实说明，宣传里不承诺本地方言"准确"。
- 面对面对话不用这行标签判断谁在说，而是靠声纹 + 识别结果的文字（中文字还是英文字母）自动判向，会话开始前设一次 A / B 语言即可（详见 03）。

### 方言到底能做到什么（诚实表）

| 方言 / 语言 | 本地引擎 | 本地水平 | 云端（需 Key） | MVP 路线 |
|---|---|---|---|---|
| 普通话（含东北等北方口音） | sherpa-onnx paraformer 小模型（82 MB）定稿；流式 zipformer（约 30 MB）上屏 | 成熟，错字率 2–5% | 阿里百炼、火山引擎等 | 本地；可选云端精修 |
| 英文 | 流式 zipformer 中英双语上屏 + sherpa-onnx whisper base.en int8 定稿（两端一致；体积与错词率待实测） | 可用（待实测） | 全部厂商 | 本地 |
| 粤语 | SenseVoice 粤语微调版（237 MB，输出无标点，MVP 用规则加标点） | 成熟，错字率 6–12%；默认繁体，可本地转简体 | 阿里百炼、火山 | 本地；可选云端精修 |
| 四川话 | 川渝 Paraformer（238 MB） | 可用，难样本错字率约 20%，标"草稿级" | 阿里百炼、火山；讯飞 / 腾讯 v2 | 本地草稿 + 可选云端精修 |
| 上海话 / 吴语、闽南语 | **MVP 没有本地引擎**；v1.1 评估方言大包（草稿级，错字率 20–30%，需 6 GB 内存） | MVP：无 | 阿里百炼（实际准确率待验证）、火山（v1.1 接入） | **只能云端**：需 Key + 音频上云或逐段授权；没 Key / 离线时拒绝录音并说明原因 |

### 技术上怎么做（简述）

- 识别引擎统一成一个接口 `AsrEngine`，MVP 有两种实现：**sherpa-onnx 引擎**（唯一的端侧 ASR / VAD / 声纹引擎；Android 用官方 AAR，只保留 arm64 约 32 MB；iOS 用 SPM 静态库，Kotlin 直接调它的 C 接口，零拷贝传音频）、**云端引擎**（WebSocket 直连厂商）。**系统引擎插件**（iOS SpeechTranscriber / SFSpeechRecognizer、Android SpeechRecognizer）只在接口层预留，MVP 不实现、不依赖，v1.1 评估后作为设置里手动启用的可选项，不再有对应的 Swift 注入点。
- 三种引擎的输出都映射到同一套 Transcript 数据结构（附录 A），置信度没有就填空，不伪造。
- **两个方言模型同时在内存里**：≥ 6 GB 内存的手机允许两个定稿模型常驻；4–6 GB 切换时卸载重载（约 1–2 秒，界面显示"切换模型中"）；< 4 GB 只允许基础包。实时翻译更严格：任一时刻只驻留一个识别模型 + 一个语音合成，端侧大模型永远不进实时路径。

### 模型怎么发给用户（我们没有服务器）

- 基础包（普通话 82 MB + 流式 zipformer 30 MB + VAD 2 MB + 声纹 28 MB ≈ 143 MB）**随 App 内置**——声纹包内置是因为面对面判向必须用，不能等首次联网。
- 粤语包（237 MB）、川渝包（238 MB）、**中 ↔ 英 NMT 语言对包（opus-mt int8，每方向约 80 MB，双向约 160 MB；出门预热引导会强制预下载）**、标点包、可选的语种识别包（98 MB）走 **iOS Apple-Hosted Background Assets**（注意：老的 On-Demand Resources 已被苹果弃用）和 **Android Play Asset Delivery**，都是苹果 / 谷歌托管，不违反"无自有 CDN"。
- 国内没有谷歌服务的 Android 商店不支持 PAD，走**手动导入**：用户从文件 / 微信 / AirDrop 把 `.sherpa-pack`（zip + 清单 + 校验值）放进 App。App 内提供公开直链（GitHub / HF / ModelScope）并标注"第三方站点，可达性不保证"。
- 首发三个模型包的许可证需要**上架前法务复核**（转换仓库没写许可字段，基座模型受 FunASR 许可约束）。

## 2.2 需求 2：自动翻译与多语展示

### 用户看到什么

- 录音场景：**三栏对照**（原文 / 润色 / 译文），段落联动高亮。方言家庭三层显示：方言原文 → 普通话（简 / 繁）→ 可选外语。
- 面对面 M3 双屏：上半屏我的语言，下半屏对方语言旋转 180°；各自有一个"朗读给对方"的黄标按钮，默认关。M1 对方半屏：灰字是正在识别、黑字是定稿，字号 ≥ 28 pt，呼吸灯表示"我在听"，句尾打勾表示"收到了"。
- 屏内字幕：默认只显示译文，双语时原文小字在上，保留最近两句；正在识别的字只在同一条字幕里原位替换，不闪。
- 术语表命中的词高亮，点一下改译法就写回术语表；屏内字幕长按可"纠错 / 加入词库 / 复制"，加入词库后同一视频后面的字幕立刻重翻。

### "方言原文"这一层是什么

粤语识别模型输出的是粤语书面字（繁体，如"佢哋 / 唔該"），这是真正的方言原文。四川话和上海话的识别模型输出的本来就是普通话汉字加少量方言词，所以这一层 = 识别原文 + 方言词注释（本地词表，如"要得 → 好的"），界面标注"识别引擎已按普通话书写"。

### 技术上怎么做

- **有 Key 且厂商有专用翻译模型**（阿里）：先用 `qwen3.8-flash` 润色，再用 `qwen-mt-flash` 翻译（92 种语言含粤语；支持把术语表和翻译记忆作为参数传入）。这是默认路线。
- **有 Key 但没有专用翻译模型**（Claude Haiku / GPT / 自定义端点）：目标语 ≤ 3 种时并入润色的一次调用，多了就拆成"润色 → 并行翻译"。
- **实时快路径**（03）：不经过润色，直接把稳定的半句或整句送去翻译；1.5 秒没回来就自动降级到端侧 NMT；上一句译文作为上下文保证指代一致。会话结束后慢路径再整段重译一遍，但**不改已经播过的内容**。
- **没 Key / 离线：端侧 NMT（两端一致，不看平台）**——

| 翻译档 | 引擎 | 语言对 | 阶段 | 说明 |
|---|---|---|---|---|
| 云端（有 Key 时首选） | qwen-mt / Claude Haiku 4.5 / Gemini Flash-Lite，用户 Key 直连 | 厂商全部语言对，含粤语 | MVP | 快路径 1.5 秒超时自动降到端侧 NMT |
| **端侧 NMT（默认离线档）** | `core/nmt`：ONNX Runtime（与 sherpa-onnx 共用运行时）+ opus-mt int8 + SentencePiece 分词 | 中 ↔ 英（每方向约 80 MB，按需下载）；其他语言对按 opus-mt 可用模型 v1.1 逐对评估 | MVP | 语言对模型没下载时入口提示下载；术语表通过 S0 前置替换 + 占位符回填生效 |
| 系统翻译插件（可选） | Apple Translation（iOS 18+）/ ML Kit Translation（需谷歌服务） | 系统语言表，都无粤语 | v1.1，设置里手动启用 | MVP 不实现、不依赖；启用后其语言包由系统下载 |

- **粤语 → 普通话在没 Key 时的真实能力 = 只做繁简和用字转换**（"佢哋"不会变成"他们"），界面会标注"仅繁简转换，未翻译粤语词汇"。有 Key 时由 qwen-mt 做真正的翻译。

## 2.3 需求 3：风格与场景切换

- **场景是一等公民**（首页的卡），**风格是场景里的二级选项**：中性 / 正式 / 口语 / 商务 / 学术 / 社交媒体 / 自定义（一句话描述 + 最多 3 条示例）。
- **切风格不重新识别，只重跑润色**；本地有缓存就是瞬时切换。屏内切风格从当前位置往后重翻，不重新转写。
- 提示词由独立模块拼装（固定约束块 + 风格块 + 场景块 + 术语块 + 输出模板块 + 个人示例块），十几段带版本号的文本，版本号进缓存键；自定义风格的版本号 = 内容的哈希，内容一变缓存自动失效。
- **实时翻译只用一句话级的语气提示**（旅行 = 简短礼貌；商务 = 正式全称；家庭 = 亲昵；日 / 韩目标语决定敬体 / 常体），不拼完整提示词——延迟不允许。
- **风格 × 场景兼容矩阵**（R 推荐 / A 允许 / B 禁用）：

| 场景 \ 风格 | 中性 | 正式 | 口语 | 商务 | 学术 | 社媒 | 自定义 |
|---|---|---|---|---|---|---|---|
| 面对面对话 | A | A | **R** | A | B | B | A |
| 速译一句 | A | A | **R** | A | B | B | A |
| 讲座旁听 | A | A | B | B | **R** | B | A |
| 屏内 · 看视频字幕 | A | B | **R**（字幕语体） | B | A | B | A |
| 屏内 · 看课程笔记 | A | A | B | B | **R** | B | A |
| 屏内 · 看剧口语 | A | B | **R** | B | B | A | A |
| 会议 | A | A | A | **R** | A | B | A |
| 口述 · 发微信 | A | A | **R** | A | B | A | A |
| 口述 · 写邮件 | A | **R** | B | A | A | B | A |
| 口述 · 发社媒 | A | B | A | B | B | **R** | A |
| 方言家庭 | A | B | **R** | B | B | B | A |
| 课堂 | A | A | B | B | **R** | B | A |
| 采访 | **R** | A | A | A | A | B | A |
| 客服 | A | **R** | B | A | B | B | A |

（"字幕语体"= 口语风格 + 字幕约束：短句、不超两行，不算第八种风格。）

- **离线时的风格降级**：本地小模型只保留中性 / 正式 / 口语三档；用户离线时选了商务 / 学术 / 社媒，风格选择器上直接显示"离线将按正式风格处理"，不悄悄降级；恢复在线后一键按原风格重跑。实时离线档（端侧 NMT）不接受任何风格指令，界面标"离线 · 基础质量"。
- **口述成稿的风格由入口决定，不猜目标 App**：iOS 在你点分享目标之前不可能知道你要发去哪；所以做成三张固定子卡（发微信 / 写邮件 / 发社媒），每张绑一个入口参数。
- 场景配置可导出为 `.scene` 文件（不含 Key、不含个人语料，见 04）。

## 2.4 需求 4：自动润色

### 五步管线

```
识别原文（带时间戳 / 说话人 / 语言）
 → S0 规则层：去口癖（有白名单）、重复折叠、按停顿加标点断句、数字归一化（"十二点半"→"12:30"）、术语表替换、敏感信息打占位符
 → S1 分段：每段 150–300 个 token，带前后各一段上下文
 → S2 大模型一次产出 {润色文本, 修改列表, 标记列表}，最多 3 路并发
 → S3 本地校验：事实守恒、术语命中、改动幅度分档、JSON 宽容解析 + 重试 1 次
 → S4 三栏对照 + 差异高亮 + 逐段接受 / 回滚 / 手改（每一版都存）
```

**与实时翻译的关系**：实时那一句只跑 S0 的轻量子集（数字归一 + 术语命中 + 占位符）就直接去翻译；**慢路径 = 完整 S0–S4**，在会话结束时对整段一次性执行（中途空闲 ≥ 20 秒只做规则层增量，不调大模型，也不加载本地模型——一顿 30 分钟饭桌对话会有很多次 20 秒空档，每次都整段重跑既费钱又费内存）。慢路径**永远不改已经播过 / 显示过的内容**，只补写字段并打"精修"标签。

> 名词澄清：屏内字幕"灰字变白字"是实时路径内的定稿替换（我们叫"定稿"），**不是**慢路径；本文的"慢路径"只指会话结束后的整段 S0–S4。

### "不许改事实"怎么检查（S3 可执行定义）

- 比对基准是 S0 之后的文本（数字已归一），不是原始文本。
- **数字 / 日期 / 金额**：两边各做一次归一化再抽取集合，润色后的集合必须包含润色前的；"十二点半"和"12:30"归一后相等，不算改。
- **专名**：只检查两类端侧能识别的——术语表命中项、原文中的大写 / 引号 / 书名号跨度；不做通用命名实体识别（技术栈里没有中文 NER）。
- **否定词**：只检查句法主干的"不 / 没 / 未 / 别 / 无法 / 不能 + 动词"，白名单口癖（"不是，"句首、"不不不"、"不好意思"）不算。
- **改动幅度阈值按风格分档**：中性 / 口语 30%、正式 / 商务 45%、学术 / 社媒 / 自定义 60%；超过只标黄提示，不判失败。
- **失败动作**：标 `fact_check_failed`，这段显示 S0 后的文本，`accepted = false`，不计入接受率分母。大模型自己报的"不确定"标记单独显示为"模型自认不确定"，两者不混。

### 修订与回滚

- 每次换风格 / 换后端重跑都追加新版本，不覆盖；"回滚"= 上一版 → 规则整理版 → 原始识别。手改也存成新版本并打上"用户改过"标记。
- **云端更准的识别结果晚到时，如果这段用户已经手改过，只挂一个"有更准的识别版本"提示，不自动替换、不自动重跑润色。**

### 降级阶梯：云端大模型 → 系统模型 → 本地模型 → 规则层

云端 LLM（阿里 `qwen3.8-flash` 默认；智谱 GLM-4.7-Flash 目前免费）→ 系统模型（iOS 26 Foundation Models，需 Apple Intelligence 机型且大陆未开放；Android ML Kit GenAI，需 AICore 机型 + 谷歌服务）——MVP 机会性接入，不可用时提示"本机无系统模型，成稿需配置 Key 或等 v1.1 本地模型"→ 本地 GGUF 模型（Llamatik + Qwen3.5-2B，需 6 GB 内存 + 电量 > 30%，**v1.1，只进慢路径**）→ 规则层永远可用（含"时间轴要点"模板：按停顿和 3 分钟窗口分组 + 数字日期高亮 + 待办候选句）。

| 出错 | 动作 | 重试 | 影响范围 | 用户看到 |
|---|---|---|---|---|
| 401 / 403（Key 失效） | 停用该 Key，会话进入"需要处理" | 否 | 该厂商全部待处理段降到下一层 | 本地通知 + 设置页红点 |
| 429（限流） | 指数退避 1 / 2 / 4 秒 | 3 次 | 仅当前段 | 胶囊"云端限流，稍后重试" |
| 余额耗尽 | 同 401，并触发本地消费闸门检查 | 否 | 同 401 | 本地通知 |
| 超时（> 30 秒） | 重试 1 次后降到下一层 | 1 次 | 仅当前段 | 段内小字"已本地整理" |
| JSON 解析两次失败 | 降到下一层 | 0 | 仅当前段 | 段内小字 |
| 没网 | 段标"待上云"，联网后补 | 联网后 | 全部段 | 胶囊"离线，已本地整理" |
| 发热严重 / 电量 < 20% | 关掉流式引擎，只保留定稿 | — | 会话 | 胶囊显示原因 |

会议场景抽出来的待办可以一键写进系统提醒事项 / 日历。用户手改的差异会沉淀为个人风格样本（v1.1）。

## 2.5 需求 5：端侧与云端切换

### 用户看到什么

- 场景编辑页里一个三态开关"仅本机 / 自动 / 优先云端"，叠加四档隐私（锁定 / 仅本机 + 逐段授权 / 仅文本上云 / 音频上云）。实时场景另有档位胶囊（MVP 只有"离线 / 混合"两档，"在线"v1.1，"一体化"v2），默认"混合"。
- 录音页 / 实时页顶部**常驻一个去向胶囊**："本机识别，未出站" / "音频段 → 阿里百炼" / "文本 → 阿里百炼" / "局域网 → 3 台设备（仅音频）"。
- 草稿级段落长按 → "精修这一段（12 秒，预计 ¥0.004，去向阿里百炼）"，精修版可回退。**问过一次就记住**：同一会话不再逐段打断。
- 首次启用某个云厂商弹一次显式同意（App Store 要求）。

### 路由 × 隐私档组合表（代码里 `decide()` 的唯一真相；不合法组合界面置灰并解释）

| 路由 \ 隐私 | 锁定 | 仅本机 + 逐段授权 | 仅文本上云 | 音频上云 |
|---|---|---|---|---|
| 仅本机 | 全本地；润色走本地阶梯 | 全本地；长按精修 = 对这一段临时授权 | 全本地识别；润色翻译文字上云 | 全本地识别；文字上云；长按精修可用 |
| 自动 | 全本地（本地没有的方言：拒录并解释） | 本地定稿 + 按需精修（本地没有的方言：提示会话级授权后只走云端） | 本地定稿；文字上云；本地没有的方言：提示改档或逐段授权，否则拒录 | 本地草稿 + 云端精修，或本地没有时只走云端 |
| 优先云端 | **不合法**（"锁定会话不能云端识别"） | **不合法**（自动降为"自动"并提示） | **不合法**（提示"将升档为音频上云"，确认后升档） | 云端流式 + 云端定稿，本地只做 VAD 和落盘；断网 / Key 失效回落本地并在胶囊显示 |

### 技术上怎么做

- `EngineSelector.decide(scene, ctx)` 返回一条路线（识别在哪、流式在哪、定稿在哪、要不要精修），显式覆盖三态 × 四档的每一格（代码在 06）。
- 两阶段：流式结果先上屏（可变）→ 一句结束本地定稿（版本 1）→ 云端精修按时间戳对齐替换（版本 2）。相似度校验只用于"本地能识别 + 云端精修"的情况；纯云端路线直接采纳云端结果，改用时长 / 时间戳对齐。
- 失败标"待上云"，后台任务补传；补传前再检查隐私档没被改回锁定、Key 还有效（鉴权失败就停，不无限重试）。
- 端云共用同一套 16 kHz 重采样和 VAD 边界；讯飞 / 火山自己切句的结果按开始时间重新映射。
- 实时翻译的四档档位由同一个 `EngineSelector` 派生：路线决定识别档，隐私档决定翻译 / 语音能不能上云，实时降级只在档内进行、不越过隐私档（详见 06）。
