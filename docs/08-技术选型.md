## 先看这个（大白话）

- **语言与界面**：Kotlin 2.4.0 + Compose Multiplatform 1.12.0，自建 Apple 风格设计系统（不用 Material 3）；导航 Decompose；依赖注入 Koin；数据库 SQLDelight；网络 Ktor 3.5.2（经 Egress 门面）。
- **端侧识别**：sherpa-onnx 1.13.8——普通话 paraformer 小模型、中英流式 zipformer、粤语 SenseVoice、川渝 Paraformer、Silero VAD、声纹、Matcha 语音合成都在它里面；**它是唯一的端侧识别 / VAD / 声纹引擎，两端一致**，系统识别只作 v1.1 可选插件。
- **翻译三档**：有 Key 首选云端（阿里 qwen-mt / Claude Haiku 4.5 / Gemini Flash-Lite）；没 Key 默认端侧 NMT（`core/nmt`：ONNX Runtime + opus-mt 中 ↔ 英 int8 + SentencePiece，两端一致）；Apple Translation / ML Kit Translation 为 v1.1 可选插件。
- **润色**：云端 qwen3.8-flash（默认）/ GLM-4.7-Flash；系统模型机会性接入；本地 Llamatik + Qwen3.5-2B GGUF（v1.1，只在慢路径）；LLM 执行层用 Koog 1.2.0（只引 prompt executor 模块）。
- **语音合成**：系统 TTS 为主，云端语音 v1.1 可选。
- **多机**：Ktor CIO 局域网 WebSocket + Bonjour/NSD + libopus + libsodium（v1.1）。
- **屏内**：Android MediaProjection / AudioPlaybackCapture + 画中画 / 悬浮窗 + ML Kit OCR；iOS AVAssetReader / MTAudioProcessingTap，ReplayKit 实验层。
- **模型分发**：随包内置 + Apple Background Assets / Play Asset Delivery + 手动导入。
