## 与执行计划的偏差（已回写 13 篇版本表）

- compileSdk / targetSdk 36 → **37**：Compose 1.12.0 与 okhttp-android 5.5.0 要求 ≥ 37。
- material3 显式锁 **1.9.0**：CMP 1.12.0 插件内置访问器映射到该版本；`compose.*` 访问器在 1.12 已弃用，全部改为显式坐标。
- `androidLibrary {}` → `android {}`：AGP 9.1.1 的 KMP 库插件新 DSL。
- SQL 不用 UPSERT：minSdk 26 的系统 SQLite 为 3.18，`upsertGlossary` / `upsertCorrection` 用 `INSERT OR REPLACE` + 子查询实现。
- Kotlin/Native 平台库里 `AVAudioSession` 的 `availableInputs` / `currentRoute` / `setActive` 是扩展成员，需显式 import。
- kotlinx-coroutines-test 1.11：`backgroundScope` 里的协程要用 `runCurrent()` 驱动，`advanceUntilIdle()` 不会执行。
