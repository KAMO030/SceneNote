## 已知限制 / 后续

- 模拟器必须用 `open -a Simulator` 打开 Simulator.app 后再启动 App，否则 `AVAudioEngine.inputNode` 初始化会在 AudioToolbox 内 RPC 超时 abort（已加 `inputAvailable` 前置拦截）。
- `simctl install` 对同版本 bundle 可能不替换，脚本一律先 `uninstall`。
- Android 焦点永久丢失（AUDIOFOCUS_LOSS）后 `ensure()` 会重新申请；iOS 打断结束依赖 `Interruption(false)` 后重新 ensure。
- 评审剩余低危项（KeychainSecureStore remove+add 非原子、AudioSink 每 ViewModel 一实例等）记入待办，不阻塞 I2。

3. 通过后提交：`git add -A && git commit -m "I1: 采集与播放（双端采集/AAC 落盘/自检页/深链/延迟打点）"`。
