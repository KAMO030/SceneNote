## 动效时间线（1.6 s，Reduce Motion 压到 0.6 s 只剩淡入淡出）

渐变铺开（0–0.20）→ 记记酱弹入（0.04–0.40，easeOutBack）→ 猫耳抖 + 呆毛摆（0.26–0.78）
→ 眨眼（0.50–0.66）→「场记 / SceneNote」贴纸字出来（0.36–0.72）→ 声波扩散（0.34–0.94）→ 淡出（0.88–1）。
