## 2. 已在真机确认（vivo V2436A，Android 16）

- 分享深链 `scenenote://screen?shared=<cache/media/test0.mp4>` 冷启动：抽音 0.6 s（10 s 视频）→ 转写 0.6 s → 4 条 cue 全部正确配到 SenseVoice 定稿 → 导出 SRT 弹出分享面板（211 B）。
- 实时会话与屏内字幕**同时**跑（两路流式会话）不再崩溃（之前共用一个 native VAD → SIGSEGV）。
- 系统字幕：点「开始」弹系统「录制或共享屏幕」；授权后状态栏出现「屏幕共享中」、页面「正在听」；停止后前台服务退出。
- 三个真机问题及根因：① 两路会话共用 VAD → 崩溃；② `scene/listen?autostart=1` 深链启动过一次后，进程被杀再从桌面 / 安装器打开会被系统原样重放 → 自动开始录音（跳板 Activity 解决）；③ 深链里的 `my=`/`other=` 曾写入用户设置（已改为只作用于本场会话）。

## 3. 需要你来测的

1. **S4 真视频**：相册里一段 10 分钟 1080p 英文视频 → 首条字幕 ≤ 5 s、整片转完 ≤ 1/4 时长（验收标准）；字幕没跟上时是否自动暂停、跟上后自动继续。
2. **分享面板**：从相册 / 微信「分享」一个视频到场记，应直接进播放器。
3. **系统字幕 S1**：授权后切到 YouTube / B 站 / 网课 App 播放，看字幕是否出现；哪些 App 报「不允许抓取」请记下（填兼容表）。
4. **PiP**：播放器 / 系统字幕页点「悬浮」→ 回桌面看小窗字幕条。
5. **iOS**：文件 App 里长按 `.mp4` → 共享 → 场记；PHPicker 选视频。
