## 2. 平台实现与真机验证项

### 已在 vivo V2054A 上确认
- 传感器：`PostureSensor start: motion=gravity proximity=alsps Proximity Sensor light=alsps Ambient Light Sensor`（三者都在）；平放桌面时姿态 = FLAT 且规则生效（见上表修复项）。
- 媒体会话：Live 期 `dumpsys media_session` 显示 `Media button session is dev.scenenote.app/SceneNoteLive`。
- 磁贴：`pm dump` 中两条 `QS_TILE` 服务已注册；M1 / M3 页面在 vivo 上按原型渲染（`截图/I4-vivo-m1.png`）。

### 需真机验证（未验证）
- 有线 / 蓝牙耳机单击 / 双击 / 三击是否到达 MediaSession（vivo ROM 可能自带映射；iOS playAndRecord 下 Now Playing 是否收键）。
- 竖起 1.5 s 进 M1 / 放平 1 s 回 M0 的手感（阈值 0.8 g、稳定 0.15 g / 1.2 m/s²）；夜间近距离传感器误报。
- vivo Android 11 `PowerManager` 热状态是否随发热变化（可能恒 NONE）；电量 < 20% 翻转。
- iOS：AppIntents 出现在快捷指令 / Action Button 列表；M1 / M4 常亮最亮与后台还原。
- 退出语 / 开场白经当前输出路由播放：戴耳机时对方听不到（决策 19「耳机只是输出设备」下不做强制外放；如需，共享层要加 RouteManager.overrideSpeaker）。
