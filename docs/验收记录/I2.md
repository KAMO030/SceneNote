## 决策 / 事实（I2 调研核实）

- 四川话：`sherpa-onnx-paraformer-zh-int8-2025-10-07`（Paraformer-large 川渝微调，非流式，WSChuan CER 12.2 vs 原版 14.3）。现行做法：流式草稿用中英 zipformer，定稿用川渝 Paraformer 覆盖。
- 中英流式：2023-02-20 bilingual int8（189 MB）；2026-06 的 X-ASR zh-en（自带标点、更准）只在 GitHub tar.bz2 里，列为 v1.1 评估项。
- SenseVoice 与 Paraformer 底座为 FunASR MODEL_LICENSE（非 Apache），上架前法务复核（附录 B 已有）。
- Kotlin/Native 正则不支持 `\p{IsHan}`，S0 用 Unicode 区间。

## 修复记录

- Android Manifest 的 `.SceneNoteApp` / `.MainActivity` 按 namespace `dev.scenenote.app` 解析导致 ClassNotFoundException（I0 起即存在，vivo 上此前从未真正启动）→ 改全限定名。
- iOS：AudioSink.prime 先把 AVAudioEngine 以纯输出启动，之后 inputNode 格式为 0 Hz → installTap 前先 stop 引擎。
- Egress：模型资产下载在「逐段授权」档被拦 → MODEL_ASSET 除锁定档外放行。
- 流式会话：VAD 判定晚于真实起点导致句首丢字 → 300 ms 预滚补喂。
- vivo 的 USB 安装确认改为 adb `uiautomator dump` + `input tap` 自动点击（用户已授权）。
