## 3. 需要你来测的

1. **术语命中**：术语表加一条（如「场记 → SceneNote」），面对面对话说到它 → 译文里应用该译名（有 Key 时）。
2. **账本一致**：用 Key 翻几句 → 设置 → 数据去向：「文字」KB 与逐条相加一致，估算花费 > 0。
3. **通知**：录一段会议 → 停止 → 10 分钟后应收到「纪要整理好了」；点开直达纪要页。Android 13+ 首次启动会弹通知权限，拒绝则不发。
4. **小组件**：桌面长按 → 添加小组件 → 「场记」→ 点「仅听」应直接开始。
5. **隐私默认档**（待决策）：目前默认「每次询问」；若改「只发文字」，改 `AppSettings.privacy` 默认值即可。
6. iOS：通知权限弹窗与 10 分钟通知；`scenenote://glossary` / `ledger` 页面外观。
